# Перегруз

Педаль дисторшна для музыки на Android (10 и новее).

Приложение подключает эффект к звуку плееров, которые сообщают системе о своей аудиосессии (Spotify и многие другие), а в экспериментальном режиме пытается обработать весь звук телефона.

Готовый APK: раздел **Releases → peregruz-latest → Peregruz.apk**. Собирается автоматически GitHub Actions при каждом пуше в ветку `peregruz`.
